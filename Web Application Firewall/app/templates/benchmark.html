Methodology & Evaluation Metrics

The benchmark test runner simulates requests against the ModSecurity engine using standard HTTP transactions across 7 threat domains: SQL Injection, XSS, Command Injection (RCE), LFI, SSRF, Scanner Probes, and Benign Clean Traffic.

  • Sensitivity (100% target): Measures the percentage of true cyber attacks neutralized at the perimeter.
  • Specificity (100% target): Ensures that normal business users and harmless searches never get falsely blocked (Zero False Positives).
Evaluation engine: OWASP Core Rule Set 3.x Anomaly Scoring Evaluation (Threshold: 5)
